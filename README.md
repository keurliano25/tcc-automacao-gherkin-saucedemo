# Automação de Testes do TCC — Gherkin e Inteligência Artificial Generativa

## Sobre o projeto

Este repositório faz parte do Trabalho de Conclusão de Curso (TCC) intitulado **“Avaliação de processos de Inteligência Artificial Generativa na Geração e Automação de Cenários de Teste em Gherkin (BDD) para Apoio à Qualidade de Software”**.

O projeto tem como objetivo disponibilizar o código-fonte utilizado na automação dos testes da aplicação SauceDemo, permitindo a consulta à implementação e favorecendo a transparência dos procedimentos realizados na pesquisa.

## Contexto da pesquisa

O experimento compara diferentes condições de utilização de Inteligência Artificial Generativa para a geração de cenários de teste. Os cenários considerados adequados para automação foram implementados em scripts de teste utilizando Playwright.

Os códigos deste repositório correspondem à implementação realizada pelo pesquisador para a execução dos testes. A automação foi desenvolvida em Playwright, não sendo resultado de uma conversão automática de Gherkin para Cucumber.

## Tecnologias

- **Playwright:** biblioteca utilizada na automação dos testes.
- **SauceDemo:** aplicação utilizada como ambiente experimental.
- **JavaScript/Node.js:** tecnologias utilizadas caso correspondam à implementação disponibilizada.

## Organização do repositório

A estrutura dos arquivos será apresentada conforme a organização efetiva do código-fonte disponibilizado neste repositório.

## Finalidade acadêmica

Este repositório foi criado para fins acadêmicos, como material complementar ao Trabalho de Conclusão de Curso. Sua disponibilização busca facilitar a consulta ao código-fonte e a compreensão da implementação utilizada no experimento.
